PAQUETE RECONSTRUIDO — RETAIL BOLD / PUNTO 2

Incluye:
- index.html: página principal rediseñada.
- css/styles.css: sistema visual Retail Bold responsive.
- LEEME.txt: instrucciones.

Compatibilidad y límites:
- No incluye ni reemplaza js/app.js.
- Conserva los selectores de integración: #filtro-categoria, #product-count y .contenedor-productos.
- Conserva el enlace a pages/shopcar.html y la carga de js/app.js.
- No se inventaron fotografías reales. El hero muestra un espacio reservado para colocar una fotografía auténtica.
- El diseño de las tarjetas se adapta a clases habituales; el acabado exacto depende del HTML que genera tu app.js actual.

Instalación:
1. Haz una copia de seguridad de tu repositorio.
2. Copia index.html a la raíz y reemplaza el archivo existente.
3. Copia la carpeta css/ y reemplaza css/styles.css.
4. No borres ni reemplaces js/app.js, pages/shopcar.html ni otros archivos.
5. Abre con Live Server o publica en GitHub Pages y prueba el filtro, el contador y el enlace del carrito.
